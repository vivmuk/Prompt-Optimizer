Skill Vault

Every generator in this app ships as a portable, tested viv-*.md skill. Drop any folder into Claude Code, Codex CLI, Cursor, Gemini CLI or Hermes — they all load the same Agent Skills standard. Each skill was executed and verified against the live Venice API before publishing. All MIT licensed.

How to install
  1. Download a viv-<name>.md file below.
  2. Rename it to SKILL.md inside a folder named after the skill, e.g. viv-be-ambitious/SKILL.md.
  3. Drop the folder into your agent's skills directory (e.g. ~/.claude/skills/, ~/.hermes/skills/, or your project's .agents/skills/).
